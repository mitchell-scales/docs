The Datasets page lists every dataset available to you, with views for filtering by recency, favourites, and usage.

## Top Bar

The top bar switches between different views of the dataset list.

| Tab | Description |
| --- | --- |
| **Recently Viewed** | Datasets ordered by when you last viewed them. |
| **Favorited** | Datasets you've starred. Press the star icon on any dataset to add it here. |
| **Workflow** | Datasets used in workflows. |
| **Transformation** | Datasets used in transformations to generate activities. |
| **All** | Every dataset, regardless of recency or usage. |

## Row Actions

Each dataset row offers two ways to take further action.

<Columns cols={2}>
  <Card title="Options menu (⋮)" icon="ellipsis-vertical">
    Opens further actions — see below.
  </Card>

  <Card title="Information (i)" icon="circle-info">
    Opens a column plan preview, showing the activities that build up the dataset's definition — no need to open the dataset itself.
  </Card>
</Columns>

The options menu (⋮) covers the following:

| Action | Description |
| --- | --- |
| **Control** | Opens the dataset editor to change the dataset's definition. |
| **Edit properties** | Edit the title, permissions, description, and folders. |
| **Share** | Share the dataset with an existing team. |
| **Add to folder** | Add the dataset to a folder, or create a new one. |
| **Create workflow** | Quickly create a **Materialization** or **Google Sheets** workflow. |
| **Create transformation** | Build activities from this dataset. |
| **Delete** | Deletes the dataset. |
