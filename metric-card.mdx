Metric cards display your most important numbers prominently.

## Basic Metric Card Requirements

You need edit access to the report and the correct user permissions to make changes. You also need to be in the report's edit mode — changes made outside edit mode won't save.

### Adding a Metric Card

Select **Metric Card** from the data elements panel on the right.

  ![Create A Plot](/images/Create-a-plot.png "Create A Plot")
</Frame>

Choose a **source type** — either **Models** or **Dataset**.

  </Card>

  <Card title="Dataset" icon="table">

### Card Style

Pick your card style — **Big Numbers** or **Breakdown**.

#### Big Numbers

Displays multiple metrics as large figures side by side. A comparison is mandatory, shown as a percentage, a value, or a delta depending on how it's configured — see Comparison, below.

#### Breakdown

Displays a single metric broken down by a dimension — for example, emails opened by campaign. Requires a dimension to be added, and a comparison is mandatory here too.

<Note>
  Adding a breakdown automatically limits it — shown as, for example, "Top 8 by value." This number can be changed.
</Note>

## Advanced Metric Card Properties

### Data Range

<Card title="Range" icon="calendar-range" horizontal>
  Type a preset range in plain English — This Week, This Month, This Year, This Quarter, 12 Months, 2 Days, and so on — or switch to a **custom period** and pick two exact dates.
</Card>

<Note>
  Unlike a plot, a metric card has no granularity setting — it shows a single point, not a series over time.
</Note>

<Frame>
  ![Screenshot 2026 07 30 At 15 21 33](/images/Screenshot-2026-07-30-at-15.21.33.png "Screenshot 2026 07 30 At 15 21 33")
</Frame>

### Filtering

Filters work the same way as [dataset filters](/activity-dataset-config) — pick a dimension (only dimensions attached to the metrics on this card are shown), set an operator, and a value.

<Columns cols={2}>
  <Column>
    - **Equals** — the dimension matches this value exactly.
    - **Not Equals** — the dimension does not match this value.
    - **Contains** — the dimension includes this text.
    - **Does Not Contain** — the dimension does not include this text.
    - **Starts With** — the dimension begins with this text.
    - **Does Not Start With** — the dimension does not begin with this text.
    - **Ends With** — the dimension ends with this text.
    - **Does Not End With** — the dimension does not end with this text.
  </Column>
  <Column>
    - **Is In** — the dimension matches any value in a list.
    - **Is Not In** — the dimension matches none of the values in a list.
    - **Any Contains** — the dimension contains any value from a list.
    - **None Contains** — the dimension contains none of the values from a list.
    - **Is Null** — the dimension has no value.
    - **Is Not Null** — the dimension has a value.
    - **Is Empty** — the dimension is an empty string.
    - **Is Not Empty** — the dimension is not an empty string.
  </Column>
</Columns>

Press the **\+** next to Filter to add one. **Add Rule** adds a single condition, **Add Group** nests a block of conditions.

**Allow Report Setting** works the same way here as elsewhere, with two explicit options:

<Columns cols={2}>
  <Card title="Enable by default" icon="toggle-on" horizontal>
    Report-level filters supersede this card's own filters.
  </Card>

  <Card title="Disabled" icon="toggle-off" horizontal>
    The card stays filtered exactly as set up here, and does not respond to report filters.
  </Card>
</Columns>

### Comparison

A comparison is mandatory on every metric card. Switch between **Previous Range** and **Previous Year**.

<Frame>
  ![Screenshot 2026 07 30 At 15 22 03](/images/Screenshot-2026-07-30-at-15.22.03.png "Screenshot 2026 07 30 At 15 22 03")
</Frame>

Press **Config All** to control how that comparison displays, for both Big Numbers and Breakdown cards.

<Columns cols={1}>
  <Card title="Comparison View" icon="percent" horizontal>
    Choose how the comparison displays — as a **Percentage**, a **Value**, or a **Delta**.
  </Card>

  <Card title="Higher Is Better" icon="arrow-up" horizontal>
    Controls how a comparison's color is read. Toggled on, an increase displays as a positive change — suited to metrics like profit. Toggled off, an increase displays as negative instead — suited to metrics like accident count, where more is worse.
  </Card>
</Columns>
