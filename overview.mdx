The Overview page is the landing page for Infrastructure — a holistic view of the transformations and processing happening across the account. Each area it surfaces is covered in more detail on its own tab ([Streams](/streams), [Activities](/activities), [Transformations](/transformations), and so on); this page is just the health check.

## Streams

Below the summary cards, each stream shows its recent run history, or **No runs** if it hasn't run yet, with a link to view its latest run.

## Attention Lists

Three lists surface anything that needs a closer look:

- **Delayed Activities** — activities whose last activity row is beyond the configured freshness window.
- **Transformations Awaiting Production** — draft datasets updated within the last week and newer than production, or not yet in production.
- **Maintenance or Error** — activities and transformations currently in maintenance or error states.

## Freshness Thresholds

Standard freshness thresholds used across infrastructure, streams, activities, and tables are set in [company settings](/company-settings), and drive the statuses shown throughout this page.

| Threshold | Meaning |
| --- | --- |
| **Green** | Freshness at or under this age is shown as healthy. |
| **Yellow** | Freshness between green and red is shown as delayed. |
| **Red** | Freshness at or beyond this age is shown as stale. |
