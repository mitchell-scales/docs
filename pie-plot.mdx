A pie plot shows how a metric's total splits across a breakdown, as segments of a whole. Unlike Line, Bar, and Stack, a pie plot is always cumulative — there's no Over Time mode.

<Frame>
  ![Pie plot](/images/Screenshot-2026-07-02-at-15.49.46.png)
</Frame>

<Tip>
  **Example use cases:** showing the split of revenue across product categories, or the proportion of leads coming from each channel, for a single period.
</Tip>

## Basic Pie Chart Requirements

You need edit access to the report and the correct user permissions to make changes. You also need to be in the report's edit mode — changes made outside edit mode won't save.

### Adding a Pie Plot

Select **Plot** from the data elements panel on the right.

<Frame>
  ![Create A Plot](/images/Create-a-plot.png "Create A Plot")
</Frame>

Then choose **Pie** as the plot type.

<Frame>
  ![Screenshot 2026 07 30 At 13 43 23](/images/Screenshot-2026-07-30-at-13.43.23.png "Screenshot 2026 07 30 At 13 43 23")
</Frame>

### Adding Data

Choose a **source type** — either **Models** or **Dataset**.

<Columns cols={2}>

  </Card>

  <Card title="Dataset" icon="table">
    Select a dataset and a tab, then add custom metrics and columns from it.
  </Card>
</Columns>

  A pie plot requires a breakdown dimension to be set — without one, there's nothing to split into segments.
</Note>

### Data Range

<Columns cols={2}>
  <Card title="Range" icon="calendar-range">
    Type a preset range in plain English — This Week, This Month, This Year, This Quarter, 12 Months, 2 Days, and so on — or switch to a **custom period** and pick two exact dates.
  </Card>

  <Card title="Granularity" icon="clock">
    Pick Day, Week, Month, Quarter, or Year.
  </Card>
</Columns>

Both Range and Granularity have an **Allow Report Setting** toggle, enabled by default — when enabled, the report-level value takes precedence; when disabled, the plot uses its own setting regardless of the report.

## Advanced Pie Chart Properties

### Breakdowns

Press the **\+** next to Breakdown to see every dimension linked to the metrics you've selected. Clicking a dimension adds it as a breakdown. Hovering over a segment shows both its value and its share of the total.

Once a breakdown is added, press **Configure** on the metric to open its settings:

<Columns cols={3}>
  <Card title="Limit Legend" icon="list-ol">
    Show the top N or bottom N values by number, rather than every value in the breakdown.
  </Card>

  <Card title="Hide Other" icon="eye-slash">
    Hides the "Other" category that appears when values outside your top N sum to more than any individual top N value.
  </Card>

  <Card title="Ranking Basis" icon="ranking-star">
    What the ranking is based on — Total (the default), Average, Current Month, or Last Month.
  </Card>
</Columns>

<Frame>
  ![Screenshot 2026 07 30 At 12 52 40](/images/Screenshot-2026-07-30-at-12.52.40.png "Screenshot 2026 07 30 At 12 52 40")
</Frame>

### Filtering

Plot filters work the same way as [dataset filters](/activity-dataset-config) — pick a dimension (only dimensions attached to the metrics in this plot are shown), set an operator, and a value.

<Columns cols={2}>
  <Column>
    - **Equals** — the dimension matches this value exactly.
    - **Not Equals** — the dimension does not match this value.
    - **Contains** — the dimension includes this text.
    - **Does Not Contain** — the dimension does not include this text.
    - **Starts With** — the dimension begins with this text.
    - **Does Not Start With** — the dimension does not begin with this text.
    - **Ends With** — the dimension ends with this text.
    - **Does Not End With** — the dimension does not end with this text.
  </Column>
  <Column>
    - **Is In** — the dimension matches any value in a list.
    - **Is Not In** — the dimension matches none of the values in a list.
    - **Any Contains** — the dimension contains any value from a list.
    - **None Contains** — the dimension contains none of the values from a list.
    - **Is Null** — the dimension has no value.
    - **Is Not Null** — the dimension has a value.
    - **Is Empty** — the dimension is an empty string.
    - **Is Not Empty** — the dimension is not an empty string.
  </Column>
</Columns>

Press the **\+** next to Filter to add one. **Add Rule** adds a single condition, **Add Group** nests a block of conditions.

**Allow Report Setting** works the same way here as elsewhere, with two explicit options:

<Columns cols={2}>
  <Card title="Enable by default" icon="toggle-on">
    Report-level filters supersede this plot's own filters.
  </Card>

  <Card title="Disabled" icon="toggle-off">
    The plot stays filtered exactly as set up here, and does not respond to report filters.
  </Card>
</Columns>

### Compare

<Warning>
  Pie plots do not support comparisons. They show composition at a single point in time, not change over time.
</Warning>

### Configure

<Columns cols={1}>
  <Card title="Hide Legend" icon="eye-slash" horizontal>
    Toggles whether the legend displays.
  </Card>

  <Card title="Show Values" icon="tag" horizontal>
    Displays the value directly on the plot.
  </Card>
</Columns>

### Annotations

Toggle **Company Events** or **Activity Events** to layer them onto the plot, or add a **Custom Annotation** of your own.

### Legend: Color and Label

Click an item in the legend to open a color picker and a label rename box, letting you recolor or relabel that segment without changing the underlying data.
