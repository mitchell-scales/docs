Tasks keeps data work, meeting notes, calendar context, planning, and processes in one place — and gives AI access to past work, current priorities, and team context so nothing gets lost.

## How It Works

<Columns cols={2}>
  <Card title="One home for data work" icon="inbox">
    Track requests, investigations, report builds, model changes, workflows, bugs, and follow-ups in one place built for data teams.
  </Card>

  <Card title="Meetings connected to the work" icon="calendar-days">
    Connect meeting notes, calendar events, decisions, follow-ups, and owners directly to the tasks and data objects they affect.
  </Card>

  <Card title="Turn requests into repeatable processes" icon="list-check">
    Create plans, checklists, approvals, steps, and reusable processes for common data work like report builds, investigations, audits, and model updates.
  </Card>

  <Card title="Plan like a team" icon="users">
    Submit requests and manage them in sprints with context, avoiding hundreds of Slack pings. The backlog can be organised by dragging and dropping tasks into the week the work should be done.
  </Card>
</Columns>
